# My Env 使用指南

My Env 是 Cindy 的全局环境变量与敏感凭据管理插件。

## 核心特性
1. **图形化安全管理**：在 Cindy 客户端「插件」→「My Env」设置页中，可视化增删改查环境变量与 Token。
2. **多变量搜索与分页**：支持实时快速搜索键名与备注，清晰分页浏览大量配置项。
3. **安全脱敏与复制**：默认脱敏展示敏感密钥，支持一键切换明文与快速复制。
4. **沙箱一键注入**：为 Agent 提供 `env_dump_for_sandbox` 等专用工具，在云端沙箱（CubeSandbox）执行 Git、CI 或构建任务时，自动注入所需凭据。

## Agent 可用工具
- `env_list`: 查看所有变量的键名与备注说明（脱敏展示）。
- `env_get`: 读取指定变量的真实明文值。
- `env_set`: 新增或更新环境变量。
- `env_delete`: 删除指定环境变量。
- `env_dump_for_sandbox`: 将环境变量整体导出为字典对象，直接传给沙箱执行命令的 env 参数。
