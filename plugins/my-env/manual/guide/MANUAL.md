# My Env 使用指南

My Env 是一个本地的环境变量仓库：在设置页录入 KEY/VALUE，随后由 Agent 单键读取，注入到云端沙箱或本地命令。

## 存储边界（请先读）

- 值以**明文**存在本插件自己的 `/kv`（宿主本机，每插件隔离，≤60KB）。
- 它**不是** `network.secrets` 凭证保险库：保险库对插件只写不可读，无法实现“Agent 读值”。
- 因此请勿存放生产级高价值凭据。GitHub 等已有官方插件的服务，优先用其主机托管登入。
- 敏感项在列表与搜索中恒为全掩码，只支持单键读取；没有批量导出工具。

## Agent 工具

- `env_list`：列出键名、脱敏值、备注、敏感标记、更新时间；支持关键词。
- `env_get`：只取一个键的明文值。仅当命令确实需要时调用，不得把值回传到对话。
- `env_set`：新增或更新一个键（`sensitive` 缺省沿用原标记，新键缺省 true）。
- `env_delete`：删除一个键。

## 并发安全

设置页每次保存都是“重读 → 只改自己那一个键 → 整体写回”，避免在 Agent 同时写入时覆盖其它变量。
