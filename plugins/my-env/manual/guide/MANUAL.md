# My Env 使用指南

My Env 是一个本地的环境变量仓库：在设置页录入 KEY/VALUE，随后由 Agent 单键读取，注入到云端沙箱或本地命令。

## 存储边界（请先读）

- 值以**明文**存在本插件自己的 `/kv`（宿主本机，每插件隔离，≤60KB）。
- 它**不是** `network.secrets` 凭证保险库：保险库对插件只写不可读，无法实现“Agent 读值”。
- 因此请勿存放生产级高价值凭据。GitHub 等已有官方插件的服务，优先用其主机托管登入。
- 敏感项在列表与搜索中恒为全掩码，Agent 侧只支持单键读取，没有批量读值工具。
- 整包导出 / 导入只存在于设置页，由用户手动点按钮完成，不作为 Agent 工具暴露。

## Agent 工具

- `env_list`：列出键名、脱敏值、备注、敏感标记、更新时间；支持关键词。
- `env_get`：只取一个键的明文值。仅当命令确实需要时调用，不得把值回传到对话。
- `env_set`：新增或更新一个键（`sensitive` 缺省沿用原标记，新键缺省 true）。
- `env_delete`：删除一个键。

## 备份与迁移（设置页手动操作）

- **导出全部**：一次点击生成整包 JSON（`schema` / `exportedAt` / `count` / `variables`，**含明文值**）
  并自动复制到剪贴板；面板里还可「下载 .json」或再次「复制 JSON」。
- **导入**：粘贴 JSON 或选 `.json` 文件；支持上面的整包格式，也兼容 `{"KEY": {"value": "…"}}`
  与 `{"KEY": "值"}` 两种简化写法。
- 冲突策略：默认只新增、已有键保持原值；勾选「覆盖同名变量」才覆盖同名键（会二次确认）。
- 会被忽略并计入提示的条目：键名不合规（非 `[A-Za-z_][A-Za-z0-9_]*`）、值为空或非字符串，
  以及 `__proto__` / `constructor` / `prototype` 这类保留名。
- 导入后仍受 `/kv` ≤60KB 限制；导出文件包含明文密钥，请自行妥善保管。

## 并发安全

设置页每次保存都是“重读 → 只改自己那一个键 → 整体写回”，避免在 Agent 同时写入时覆盖其它变量。
